# Goal setting

This is rule 0 of the six, run before work rather than in review. The
rule's definition and reasons: `/home/agent/research/Projects/Golden
Engineering Rules.md`.

Before any work on a new idea, settle three lines with me:

- **Goal:** what it's for, one level above the thing itself.
- **Out of scope:** what it won't do.
- **Done when:** how we'll both know it's finished.

Draft them yourself from what I said and what you can check. Put only the
decisions to me, each with your recommended answer, so "yes" accepts it. A
small idea gets the three lines in one message; a project gets a few rounds.

If the idea looks wrong for my goal, or not worth its cost, say so first,
with the reason, before drafting.

Stop when I confirm the lines. Write them at the top of where the work lives
(the PR body, the project's spec), and work within them.
